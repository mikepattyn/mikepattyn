# mikepattyn portfolio

Tiny personal portfolio for [Mike Pattyn](https://github.com/mikepattyn) — apps on the mikepattyn platform and the AlienButNice brand.

Lives in this umbrella repo (not a git submodule).

## Quick start

```bash
cd apps/mikepattyn
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Output goes to `dist/`.
